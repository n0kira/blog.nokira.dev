# Nokira's personal blog

![Picture](assets/README-banner.png)

Blog made for my personal website. 

## Components:
- Home Page:
  > All blog entries are here, you can see short descriptions for each one.
- Blog Post:
  > Read the full blog post in a dedicated page

## Why did I make this?

I felt like a single website with just an "About Me" section didn't make the website feel _alive_ so I decided to create a blog, in this way I can public whenever I want and people won't just look at words from the past.

## Stack:

HTML - for structure
CSS - for styling
JavaScript - for rendering

## How to host locally:

1. Clone the repo:
```
git clone https://github.com/n0kira/blog.nokira.dev
```

2. Navigate into the repo folder
```
cd nokira.github.io
```

3. Open index.html
